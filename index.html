シミュレーション結果

現在の状態

AHC のレートは全パフォーマンス履歴と各コンテストの日付に依存するため、 現在レートと参加回数だけからは一意に定まりません。ここでは 全回で同一のパフォーマンスを取り、指定間隔で開催されたと仮定して等価な履歴を逆算します（近似）。 正確に計算したい場合は「履歴 JSON を貼り付け」を使ってください。

ブラウザで https://atcoder.jp/users/ユーザー名/history/json?contestType=heuristic を開き、表示された内容をそのまま貼り付けてください。 （公式 API は CORS を許可しておらず、AtCoder Problems のプロキシは contestType を落としてしまうため、ページから直接取得できません。）

各コンテストの重み（長期 1.0 / 短期 0.5）は同梱の contests_heuristic.json から自動判定します。unrated なコンテストは計算に含めません。

今後のコンテスト

「間隔」は前回のコンテストからの日数です。AHC のレートは 直近コンテストの終了日を基準に 年あたり 100 の自然減衰を受けるため、 間隔が空くほど過去のパフォーマンスの寄与が下がります。 重みは 2025 年以降、長期コンテスト = 1.0 / 短期コンテスト = 0.5 です。
